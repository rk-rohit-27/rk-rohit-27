# About

I’m **Rohit Kumar**, a software developer from Jammu, India, focused on building practical web applications and gradually moving deeper into **AI engineering**.

My foundation is in full-stack web development, with professional experience across **React, Next.js, Node.js, Express.js, MongoDB and WordPress**. I enjoy taking an idea from the interface and API layer through to deployment and a usable product.

Currently, I’m expanding that foundation into **AI application engineering**, with a focus on:

- Python for backend and AI application development
- FastAPI for production-oriented AI APIs
- RAG systems and retrieval pipelines
- LLM-powered applications
- LangGraph and stateful AI workflows
- AI agents and tool-based workflows

I’m particularly interested in the engineering side of AI — not only prompting models, but understanding how **APIs, retrieval, state, tools, data, evaluation and application architecture** come together to build useful systems.
